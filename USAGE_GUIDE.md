## 🔧 Как использовать

### 1. **Просмотр каталога**
Перейдите по адресу: `/catalog`

### 2. **Просмотр категории**
Перейдите по адресу: `/catalog/{id}`

### 3. **Просмотр товара**
Перейдите по адресу: `/product/{id}`

## 🎨 Настройка дизайна

### Цветовая схема:
- Основной: `cyan-600` → `blue-600`
- Кнопки: `cyan-700` → `cyan-600`
- Акценты: `cyan-500`

### Изменение цветов:
1. Откройте `catalogs.blade.php`
2. Найдите классы `from-cyan-600 to-blue-600`
3. Замените на нужные цвета

### Изменение количества колонок:
```php
<!-- В catalogs.blade.php -->
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 gap-6">
```

## 🔍 Отладка

### Если что-то не работает:
1. Очистите кэш: `php artisan view:clear`
2. Проверьте маршруты: `php artisan route:list`
3. Проверьте логи: `storage/logs/laravel.log`

### Частые проблемы:
- **Компоненты не найдены** → Проверьте правильность путей
- **Маршруты не работают** → Проверьте `routes/web.php`
- **Изображения не загружаются** → Проверьте `storage/` директорию
